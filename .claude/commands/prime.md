# Prime Context

Load full project context before starting any work session.

## Steps

1. Read `CLAUDE.md` to understand the project rules, architecture, and conventions
2. Read `config.yaml` for current configuration
3. Run `git log --oneline -20` to understand recent changes
4. Run `git status` to see current working state
5. Check if the backend and extension directories exist and scan their structure
6. Read any open GitHub issues: `gh issue list --state open --limit 20`
7. Summarize what you found and ask what we're working on today
